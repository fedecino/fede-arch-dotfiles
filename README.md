# Arch Linux + Niri Desktop Sync

Configurazione esportata e dotfiles gestiti tramite GNU Stow.

## Installazione su un nuovo PC

1. Clona il repository:
```bash
git clone <URL_REPO> ~/arch_fede
cd ~/arch_fede
```
2. Esegui il bootstrap:
```bash
chmod +x bootstrap.sh
./bootstrap.sh
```
3. Riavvia la macchina.
